=================================================================================================================================================
[1단계] 백엔드 코드 수정 (로컬 VS Code)
가장 먼저 로컬 컴퓨터의 VS Code에서 전달받은 수정된 백엔드 소스코드들을 반영합니다.

main.py 수정: CORS 허용 목록에서 *를 지우고 실제 접속할 주소(로컬 Vite 포트 5173, Vercel 주소)만 등록합니다.

member.py 수정: 비밀번호 암호화(passlib/bcrypt) 로직을 적용합니다.

board.py 수정: 비밀번호 비교 부분의 오타(db_board.password == db_board.password $\rightarrow$ verify_password 검증)를 고칩니다.

requirements.txt 업데이트: 암호화 라이브러리(passlib[bcrypt], PyJWT)가 없는 경우 파일 목록에 추가합니다.
=================================================================================================================================================

=================================================================================================================================================
[2단계] Render.com 배포 및 환경변수 설정

수정한 코드를 GitHub에 올려 Render.com이 자동으로 다시 배포하게 만든 뒤, 보안 키를 설정합니다.

Git Commit & Push: 수정된 코드(main.py, member.py, board.py, requirements.txt)를 Git에 커밋하고 GitHub ilshin-website 리포지토리에 푸시합니다.

Render.com 대시보드 접속:

Environment Variables 메뉴로 이동합니다.

DATABASE_URL이 잘 등록되어 있는지 확인합니다.

WT_SECRET_KEY 는 이름으로 복잡한 문자열(예: ilshin_secret_key_2026_xyz!@#)을 새 환경변수로 추가해 줍니다. 
(코드상에 비번이 노출되는 것을 막아줍니다)
=================================================================================================================================================

=================================================================================================================================================
[3단계] 백엔드 Swagger 문서에서 최종 점검 (/docs)

프론트엔드를 만들기 전에, 백엔드가 혼자서도 잘 돌아가는지 확인합니다.

Render.com에 배포된 주소 끝에 /docs를 붙여 접속합니다. (예: [https://...onrender.com/docs](https://...onrender.com/docs))

회원가입 (POST /api/members): 새 계정을 만들어 봅니다.

로그인 (POST /api/members/login): 방금 만든 계정으로 로그인해 access_token이 정상 발급되는지 확인합니다.

게시판 (POST /api/board/free): 글 작성이 잘 되는지 확인합니다.

💡 여기까지 성공하면 백엔드 준비 및 해킹 대비 보완은 완료입니다!
=================================================================================================================================================

=================================================================================================================================================
[4단계] Vue 3 프론트엔드 통신 모듈 세팅

이제 프론트엔드(Vue 3) 작업으로 넘어가서, 백엔드와 대화할 수 있는 준비를 합니다.

Axios 라이브러리 설치: Vue 3 터미널에서 npm install axios 명령어를 실행합니다.

환경변수 파일 생성 (.env): 백엔드 Render.com 주소를 적어둡니다.

src/api/index.js 작성: 토큰을 자동으로 꺼내서 보내주는 '공통 통신 일꾼(Axios 인스턴스)'을 만듭니다.

src/api/auth.js 및 board.js 작성: 로그인/게시판용 API 함수들을 만들어 모아둡니다.
=================================================================================================================================================

=================================================================================================================================================
[5단계] Vue 3 화면(컴포넌트) 연동 개발

통신 준비가 끝났으니 실제 화면을 만들면서 백엔드 데이터를 불러옵니다.

로그인 화면 (Login.vue): auth.js를 불러와 로그인 테스트를 해보고, 성공 시 토큰이 브라우저 로컬스토리지에 들어가는지 확인합니다.

첫 화면/회사 소개: company.js나 door.js 연동으로 회사 정보나 첫 대문 정보를 백엔드에서 받아와 화면에 띄웁니다.

게시판 화면 (BoardList.vue, BoardWrite.vue): 백엔드 게시판 API와 연동하여 글 목록 보기, 글쓰기, 수정, 삭제 기능을 차례대로 연결합니다.
